# Client Website & Web Project Discovery Template

*Use this universal scoping questionnaire with any new client to clarify project scope, technical requirements, design preferences, and timeline before writing code.*

---

## 1. Project Type & Core Purpose

1. **What type of digital product do you need?**
   - [ ] **Static Informational Website** (Company showcase, portfolio, clinic/firm brochure, fast, zero server cost)
   - [ ] **Content-Driven Website with CMS** (Blog, news, case studies that you can update yourself without a developer)
   - [ ] **Interactive Web Application** (User logins, customer dashboards, saving data, custom workflows)
   - [ ] **E-Commerce Store** (Product catalog, shopping cart, online payments, order tracking)
   - [ ] **Single-Page Landing Page** (One high-converting page focused on a single product, event, or campaign)

2. **What is the #1 primary goal of this website?**
   - [ ] Generate phone calls / WhatsApp inquiries
   - [ ] Collect email leads through contact forms
   - [ ] Sell products or collect online payments directly
   - [ ] Establish brand credibility and authority
   - [ ] Educate users and answer common questions

## 5. Functionality & Integrations

1. **How should visitors contact or book with you?**
   - [ ] Standard Contact Form (Emails sent to your inbox)
   - [ ] 1-Click WhatsApp Direct Chat
   - [ ] Automated Calendar Booking (Calendly, Cal.com)
   - [ ] Direct Click-to-Call Phone Button

2. **Do you need User Accounts or Authentication?**
   - [ ] No — All visitors see the same public content.
   - [ ] Yes — Users/Clients need to create an account, log in, and view personal data.

3. **Do you need to accept online payments?**
   - [ ] No online payments needed (all payments offline / in-person).
   - [ ] Yes — UPI, Credit/Debit Cards, Netbanking (e.g., Razorpay, Stripe).

4. **Third-Party Integrations needed:**
   - [ ] Google Maps Location Embed
   - [ ] Google Analytics / Meta Pixel (for tracking visitors and ads)
   - [ ] Social Media Feed (Instagram grid embed)
   - [ ] Newsletter / Email Marketing (Mailchimp, Substack)
   - [ ] Live Chat Widget (Tawk.to, Crisp, Intercom)
