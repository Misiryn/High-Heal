# High Heal — Elite Sports Medicine & Advanced Physiotherapy

A performance-oriented, Apple-inspired static website built for **High Heal**, an advanced Sports Medicine, Biomechanics, and Physiotherapy clinic based in Ahmedabad.

---

## 🌟 Key Highlights & "Wow Factor" Features

- **Apple-Grade Aesthetic**: Deep obsidian palette (`#050811`), subtle neon emerald and surgical cyan ambient lighting, glassmorphism cards, and fluid typography.
- **Interactive Anatomy & Pain Navigator**: Users can interactively select body zones (Knee, Shoulder, Spine, Ankle, Cervical Neck, Hip) to view targeted pathologies, evidence-based clinical protocols, expected recovery timelines, and clearance benchmarks.
- **4-Phase Return-to-Play Framework**: Interactive athletic clearance timeline built on IOC and FIFA sports medicine criteria.
- **Corporate Health Economics ROI Calculator**: Interactive team-size slider estimating sick days prevented and net corporate productivity restored.
- **1-Click WhatsApp Direct Triage**: Auto-formats patient booking details (complaint, preferred time slot, symptoms) into WhatsApp for direct clinical confirmation.
- **Zero-Bloat Performance**: Built on Astro 5 static site generation with island hydration, delivering sub-second load times and 100/100 Lighthouse performance.

---

## 📂 Information Architecture (6 Core Pages)

1. **Home (`/`)**: High-impact hero, trust metrics, interactive Anatomy Explorer, Bento Grid of 4 clinical pillars, patient case studies, and booking CTA.
2. **Services (`/services`)**: Comprehensive clinical disciplines (Post-Op Orthopedic, 3D Gait Analysis, Spinal Decompression, Dry Needling CDNT, Heavy Slow Resistance Tendon Loading, IASTM & Pneumatic Recovery).
3. **Sports Physio (`/sports-physio`)**: Specialized programs for Marathoners, Cricket Fast Bowlers, Footballers, Court Athletes, CrossFit athletes, plus the 4-Phase Return-to-Play Framework and Pre-Season Screening.
4. **Corporate Wellness (`/corporate-wellness`)**: Workstation ergonomic audits, C-Suite posture masterclasses, executive physio retainers, and the interactive Corporate ROI Calculator.
5. **About Doctor (`/about`)**: Lead sports physiotherapist profile, credentials (MPT, MIAP, CDNT), clinical philosophy, private treatment suites, and sensor hardware suite.
6. **Contact & Booking (`/contact`)**: Interactive patient intake form, clinic address, Google Maps guide, operating hours, emergency trauma hotline, and patient FAQs.

## 🚀 Getting Started Locally

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Run local development server
npm run dev

# 3. Build for production (outputs static HTML/CSS/JS to dist/)
npm run build

# 4. Preview the production build locally
npm run preview
```
